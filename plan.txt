              PLAN CODE "POSTMAN MINI" (v2 - cập nhật 2026-11-19)
================================================================================

KỲ VỌNG:
- App đơn giản, giao diện dễ dùng, dễ nhìn hơn Postman.
- Càng ít thao tác càng tốt: paste cURL là chạy, Ctrl+Enter để gửi, tự lưu.

KIẾN TRÚC:
- Next.js App Router + TypeScript + Tailwind
- Lưu trữ v1: IndexedDB (idb-keyval) qua Zustand persist
    -> không cần config, không lộ token lên cloud, chạy offline.
    -> Firestore để v2 (chỉ khi cần đồng bộ nhiều máy, BẮT BUỘC có Auth + rules).
- Gửi request: LAI (hybrid)
    1. Thử fetch TRỰC TIẾP từ browser.
    2. Lỗi (CORS / mixed content / network) -> TỰ ĐỘNG gọi lại qua proxy
       Next.js Route Handler: app/api/proxy/route.ts (không cần Cloud Function).
    -> Chạy `npm run dev` trên máy => gọi được cả API nội bộ công ty, http://localhost.
    -> Có thể chọn chế độ: Auto | Direct | Proxy.
- State: Zustand | Editor + JSON viewer: CodeMirror 6 (@uiw/react-codemirror)
    -> dùng 1 thư viện cho cả body editor và response viewer (read-only, fold, search).

ĐÁNH ĐỔI (chấp nhận):
- Dữ liệu chỉ nằm trên 1 trình duyệt/1 máy (v1). Có Export/Import JSON để chuyển máy.
- Proxy chỉ chạy khi có server Next (dev local hoặc deploy Vercel). Static hosting -> chỉ Direct.

================================================================================
LƯU Ý KỸ THUẬT
================================================================================

1. Lỗi fetch chỉ là TypeError -> không phân biệt được CORS / mixed content /
   network. Thông báo liệt kê đủ khả năng + cho biết đã thử proxy chưa.
2. Đo đạc: duration = performance.now(); size = byte của body;
   proxy trả thêm header đầy đủ (direct thì một số header bị CORS ẩn).
3. CodeMirror: next/dynamic ssr:false.
4. Response lớn: chỉ hiển thị tối đa ~5MB; history chỉ lưu body tối đa 100KB.
5. History giữ 100 bản gần nhất.
6. Env: thay {{var}} trước khi gửi (url, params, headers, body, token).
7. Proxy: chặn method lạ, chỉ http/https, timeout 30s (tối đa 120s), response <= 50MB.
   Tùy chọn khóa proxy: PROXY_TOKEN trong .env.local.
   Chỉ dùng local/cá nhân - KHÔNG deploy công khai (sẽ thành open proxy).
8. Non-JSON response (HTML/text) -> hiển thị text; ảnh -> preview.
